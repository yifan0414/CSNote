经设置为持久下线。新增了 systemd 服务：

  /etc/systemd/system/offline-cpu-7-39.service

  当前状态确认：

  enabled
  Active: active (exited)
  cpu 7/online = 0
  cpu 39/online = 0
  offline = 7,39

  回滚方式：

  sudo systemctl disable --now offline-cpu-7-39.service
  sudo rm /etc/systemd/system/offline-cpu-7-39.service
  sudo systemctl daemon-reload

  因为服务里有 ExecStop，disable --now 会把 CPU 7/39 恢复上线。
