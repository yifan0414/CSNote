# 服务器下线 CPU $7$、$39$

![[_assets/images/服务器CPU下线-01-状态截图.png|900]]

## 已记录的设置

已设置为持久下线。新增的 systemd 服务为 `/etc/systemd/system/offline-cpu-7-39.service`。

当时记录的状态：

```text
enabled
Active: active (exited)
cpu 7/online = 0
cpu 39/online = 0
offline = 7,39
```

## 回滚方式

```bash
sudo systemctl disable --now offline-cpu-7-39.service
sudo rm /etc/systemd/system/offline-cpu-7-39.service
sudo systemctl daemon-reload
```

原记录说明：服务里有 `ExecStop`，`disable --now` 会把 CPU $7$、$39$ 恢复上线。
