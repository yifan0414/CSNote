# CS224N 20：多模态基础模型

> [!abstract] 本节定位
> 通过 Chameleon、Transfusion、Mixture-of-Transformers 等工作比较离散 token、扩散表示和模态路由。

## 学习目标

- [ ] 比较视觉离散 token 与连续或扩散表示
- [ ] 解释 early fusion 与模态专用参数的权衡
- [ ] 从数据、扩展、生成和奖励评估阅读统一模型

## 知识笔记

> [!warning] 资料边界
> 官网没有发布本节 PPT。以下笔记按官网列出的 11 篇论文组织：Visual Sketchpad、Chameleon、Transfusion、Mixture-of-Transformers、mixed-modal scaling、CM3Leon、RA-CM3、LMFusion、OneFlow、Multimodal RewardBench 和 Reconstruction Alignment。

## 1. 多模态模型要统一什么

多模态模型可能需要同时处理：

- text-to-text；
- image-to-text；
- text-to-image；
- image editing；
- image + text 交错输入；
- image + text 交错输出。

“统一”有多个层次：

1. 统一 token 序列；
2. 统一 Transformer 主干；
3. 统一训练目标；
4. 统一生成过程；
5. 统一接口。

一个模型共享 backbone 不代表所有模态必须共享同一 tokenizer、loss 或全部参数。

## 2. 三种视觉表示

### 2.1 连续视觉特征

视觉 encoder 输出：

$$
H_v\in\mathbb{R}^{N_v\times D}.
$$

通过 projector 对齐 LLM hidden size，再与文本 embedding 拼接。

适合理解，但若要生成图像还需要独立 decoder 或 diffusion model。

### 2.2 离散视觉 Token

VQ tokenizer 将图像编码为 codebook id：

$$
I
\xrightarrow{\text{encoder + quantizer}}
[z_1,\ldots,z_{N_v}],
\qquad
z_i\in\{1,\ldots,K\}.
$$

图像与文本都可用 next-token prediction。

优势：

- 目标统一；
- 可任意交错；
- 直接复用 autoregressive LM。

代价：

- 量化损失；
- 图像 token 很长；
- 逐 token 生成慢；
- 离散 codebook 质量限制细节。

### 2.3 连续 Latent + Diffusion/Flow

图像被编码为连续 latent：

$$
Z\in\mathbb{R}^{N_v\times D_v}.
$$

使用 diffusion 或 flow matching 学习连续去噪/速度场，文本仍用离散 next-token loss。

这保留视觉连续结构，但训练和采样目标不再完全统一。

## 3. Early Fusion 与 Late Fusion

### Early Fusion

模态在 Transformer 输入早期进入共同序列，可在所有层交互。

优点：

- 深层跨模态融合；
- 支持任意交错文档；
- 一个序列建模接口。

风险：

- 不同模态统计差异导致训练不稳；
- 文本能力可能被视觉更新破坏；
- 图像 token 数量压倒文本；
- 所有 token 使用相同参数未必高效。

### Late Fusion

先由模态专用 encoder 独立处理，再在较高层或 cross-attention 融合。

优点是可重用成熟单模态模型，缺点是跨模态交互受接口瓶颈限制。

## 4. Chameleon：全离散 Early Fusion

Chameleon 将：

- text；
- image；
- code

全部表示为离散 token，用一个 autoregressive Transformer 从头训练。

联合序列：

$$
s=[t_1,\ldots,t_m,z_1,\ldots,z_n,\ldots].
$$

目标：

$$
L
=
-\sum_i\log P(s_i\mid s_{<i}).
$$

### 关键能力

- 图像理解；
- image caption；
- text generation；
- image generation；
- 长篇图文交错生成。

### 稳定训练

Early fusion 中不同模态 logit 与 activation 统计不同。论文强调：

- query–key normalization；
- 调整 LayerNorm 位置；
- 专门的训练稳定化；
- 多模态 SFT/alignment。

这说明“把图像 id 加到词表”只是接口统一，优化仍需模态感知。

## 5. Transfusion：离散文本 + 连续图像

Transfusion 在同一 Transformer 上使用两类 loss。

文本：

$$
L_{\text{text}}
=
-\sum_t\log P(x_t\mid x_{<t}).
$$

图像 latent 扩散：

$$
L_{\text{image}}
=
\mathbb E_{z,\epsilon,t}
\left\|
\epsilon-\epsilon_\theta(z_t,t,\text{context})
\right\|^2.
$$

总目标：

$$
L
=
L_{\text{text}}
+\lambda L_{\text{image}}.
$$

### 为什么可能优于离散图像 token

- 不需要把连续图像强压到 codebook；
- 图像 patch 可大幅压缩；
- diffusion loss 更符合连续视觉生成；
- 文本仍保留成熟 LM 目标。

论文展示图像可压到少量 patch，同时保持文本和图像生成能力。

## 6. Mixture-of-Transformers

MoT 的目标是在保持全序列 global attention 的同时，让非 embedding 参数按模态拆分。

对 token $x_i$，根据模态 $m_i$ 选择：

- 模态专用 FFN；
- 模态专用 Q/K/V/O；
- 模态专用 normalization。

但所有 token 仍可在 attention 中交换信息。

### 直觉

文本 token 不必经过图像专用变换，图像 token 也不必占用全部共享计算。

与 MoE 类似，它通过稀疏激活减少每 token FLOPs；区别是路由由已知模态决定，而非学习 top-k expert。

### 论文结果的意义

MoT 在 Chameleon 和 Transfusion 设置中用明显更少 FLOPs 接近 dense baseline，说明：

- 跨模态交互需要共享；
- 模态内部变换不必全部共享；
- 稀疏结构可以同时改善算术量和实际 wall-clock。

## 7. Mixed-Modal Scaling Laws

混合模态不只是把各自 loss 相加。不同模态之间可能：

- synergy：共享结构带来正迁移；
- competition：固定容量下相互争夺参数；
- optimization imbalance：某个模态梯度主导。

可将 loss 粗略写成：

$$
L_{\text{mix}}
\approx
\sum_m L_m(N,D_m)
+I(N,D_1,\ldots,D_M),
$$

其中 $I$ 表示模态交互。

论文通过大量不同规模实验拟合：

- 模型大小；
- 各模态 token 数；
- 混合比例；
- 单模态与混合性能

的关系。

### Coordinate-Ascent 式现象

训练中可能交替改善不同模态，而不是所有 loss 同步下降。梯度冲突和容量竞争会造成阶段性主导。

因此应监测每模态：

- loss；
- gradient norm；
- token 比例；
- downstream score。

总 loss 可能掩盖某个模态退化。

## 8. CM3Leon：检索增强预训练 + 多任务 SFT

CM3Leon 是 token-based decoder-only mixed-modal model，可：

- text-to-image；
- image-to-text；
- image infilling；
- 视觉编辑与结构任务。

训练分两阶段：

1. retrieval-augmented pretraining；
2. 多任务 supervised fine-tuning。

### 对比式解码

同一个多模态模型可提供不同条件分布，用对比 logit 强化条件相关内容：

$$
z_{\text{contrast}}
=
z_{\text{cond}}
-\alpha z_{\text{weak/uncond}}.
$$

这提高 prompt controllability，类似 classifier-free guidance 的思想。

## 9. RA-CM3：多模态外部记忆

RA-CM3 用当前文档查询多模态 memory，取回图文混合文档，再条件生成。

结构：

$$
q=f_\eta(x),
$$

$$
\{z_1,\ldots,z_k\}
=
\operatorname{Retrieve}(q,\mathcal M),
$$

$$
y\sim P_\theta(y\mid x,z_{1:k}).
$$

好处：

- 不必把全部视觉事实存入参数；
- 可提高生成忠实度；
- 支持多模态 in-context demonstrations；
- 用较少训练计算获得更强结果。

风险与文本 RAG 类似：检索污染、版权、相似图泄漏和错误归因。

## 10. LMFusion：重用文本 LLM

从头训练统一多模态模型昂贵，还可能损害成熟语言能力。

LMFusion：

- 保留 Llama-3 文本模块；
- 增加并行图像模块；
- 文本与图像使用模态专用 FFN、QKV 和 norm；
- self-attention 保持跨模态交互；
- 冻结文本专用模块，只训练视觉部分。

它将已有 text-only compute investment 迁移到多模态生成。

核心思想与 MoT 相通：

> 跨模态信息可以共享 attention，而模态内部计算可以分开。

## 11. OneFlow：非自回归交错生成

Autoregressive mixed-modal generation 强制固定顺序：

$$
s_1\to s_2\to\cdots\to s_T.
$$

OneFlow 将：

- 离散文本使用 insertion-based Edit Flow；
- 图像 latent 使用 Flow Matching；
- 文本和图像并发迭代生成。

### 插入式文本生成

不是每次只在末尾追加，而是在现有序列中选择位置插入 token。可先形成高层内容，再补语法与细节。

### 能力

- variable-length；
- 多图；
- 图文交错；
- concurrent refinement；
- 非严格因果生成。

这打破“统一模型必须等价于统一 autoregressive token stream”的假设。

## 12. Visual Sketchpad：视觉 Chain-of-Thought

文本 CoT 将中间结果写成词，但几何、地图和空间关系更适合写成图。

Sketchpad 给模型工具：

- 画线；
- 画框；
- 标记；
- crop/zoom；
- segmentation；
- depth；
- 绘图。

循环：

$$
\text{Observe}
\to
\text{Draw/Tool}
\to
\text{Inspect Artifact}
\to
\text{Reason}.
$$

视觉 artifact 充当外部工作内存。

### 为什么有效

- 空间关系直接保留在二维布局；
- 辅助线把隐含约束显式化；
- 专用视觉模型补足通用 VLM 感知；
- 模型可重新观察自己产生的中间视觉结果。

### 风险

- 工具输出也会错；
- 错误框或深度图可能强化错误；
- 需要记录完整工具轨迹；
- 最终答案正确不保证每个 visual step 忠实。

## 13. Unified Model 的理解–生成错位

模型可能能识别某个罕见视觉概念，却不能生成它。

原因：图像 caption 是稀疏监督。即使描述很长，也遗漏：

- 精确几何；
- 纹理；
- 布局；
- 颜色组合；
- 实例身份；
- 局部细节。

文本只提供图像语义的低带宽摘要。

## 14. Reconstruction Alignment

RecA 使用视觉理解 encoder embedding 作为稠密条件，让统一模型重建原图。

$$
e=E_{\text{vision}}(I),
$$

$$
\hat I=G_\theta(e),
$$

$$
L_{\text{RecA}}
=
d(\hat I,I).
$$

它把模型已有的理解表示重新对齐到生成路径，无需人工 caption。

论文报告这一轻量 post-training 可同时改善：

- text-to-image；
- image editing；
- 属性和空间忠实度；
- 多种 autoregressive、masked autoregressive 与 diffusion UMM。

## 15. 多模态 Reward Model

偏好样本：

$$
(x_{\text{text}},x_{\text{image}},y_w,y_l).
$$

Reward model 要判断：

- 一般正确性；
- 人类偏好；
- 知识；
- reasoning；
- safety；
- visual QA。

Multimodal RewardBench 包含 5,211 个专家标注 triplet。论文发现领先 VLM judge 的总体准确率仍有限，reasoning 和 safety 尤其困难。

### 多模态 judge 的额外偏差

- 忽略图像只评文字；
- 偏爱更详细回答；
- OCR 或细粒度视觉错误；
- 对图像中有害内容不敏感；
- chosen/rejected 差异落在局部区域。

## 16. 统一模型设计空间

| 维度 | 选择 |
| --- | --- |
| 图像表示 | discrete token / continuous latent |
| 融合 | early / late / hybrid |
| 参数 | dense shared / modality-specific sparse |
| 文本目标 | autoregressive / masked / edit flow |
| 图像目标 | token prediction / diffusion / flow |
| 训练 | from scratch / reuse frozen LLM |
| 知识 | parametric / retrieval augmented |
| 推理 | text CoT / visual scratchpad / tools |

不存在对所有任务最优的唯一统一方式。

## 17. 训练与评测清单

> [!check]
> - 各模态 token/样本比例；
> - 各模态 loss 和 gradient norm；
> - text-only 能力是否退化；
> - 理解和生成分别评测；
> - 图文交错长序列；
> - 属性、计数、空间和 OCR；
> - 图像质量与 prompt fidelity 分开；
> - reward model 的 reasoning 与 safety；
> - 训练 FLOPs 和真实 wall-clock；
> - 数据许可、人物隐私和检索泄漏。

## 18. 小结

- 统一多模态可统一序列、主干或接口，不必强行统一所有表示与 loss。
- Chameleon 使用全离散 early fusion；Transfusion 结合文本 token loss 与图像 diffusion。
- MoT 和 LMFusion让跨模态 attention 共享、模态内部参数分开，以降低成本或复用 LLM。
- RA-CM3 将外部多模态记忆引入生成，OneFlow探索并发非自回归图文生成。
- Visual Sketchpad 把视觉 artifact 作为推理工作内存。
- RecA 用视觉 embedding 作为稠密监督，缓解理解与生成错位。
- 多模态 reward model 仍难可靠判断 reasoning 与 safety。
