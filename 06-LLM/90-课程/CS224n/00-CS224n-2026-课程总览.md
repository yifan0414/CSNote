# Stanford CS224N 2026：Natural Language Processing with Deep Learning

> [!abstract] 课程地图
> 按 Stanford CS224N Winter 2026 官网课表整理 22 个教学单元。每节笔记均从完整 PPT、Notebook 或指定阅读中提取知识正文，包含概念、公式、推导、例子、shape 与易错点，并收录课件 PDF、讲义、论文、Notebook、作业和项目文档。

## 课程信息

- 学期：Winter 2026
- 教师：Diyi Yang、Yejin Choi，另含多位客座讲者
- 主线：词向量 → 神经网络与 RNN → Transformer → 预训练 → 后训练与 PEFT → Agent 与 RAG → 评测与推理 → 多语言、可解释、多模态与影响
- 笔记来源：01–17、19、22 主要依据官方 PPT；06/13 同时依据 Notebook；18/20 依据官网指定论文；21 依据讲者发布的 Tinker 与 LoRA Without Regret 一手资料。
- 官网：[CS224N 官方课程页](https://web.stanford.edu/class/cs224n/index.html)
- 各节笔记保留了对应的原始 URL。

## 建议学习路线

1. 基础（01–07）：历史、词向量、Python、反向传播、RNN、PyTorch、Transformer。
2. 现代 LLM 管线（08–13）：项目方法、预训练、后训练、PEFT、Agent 与 Hugging Face。
3. 能力与测量（14–17）：评测、推理学习、推理加速和分词与多语言。
4. 前沿与责任（18–22）：可解释性、社会影响、多模态、高效后训练系统与开放问题。
