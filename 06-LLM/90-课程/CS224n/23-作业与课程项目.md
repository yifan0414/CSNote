## 建议执行顺序

1. 解压代码包并从原始 Notebook 或测试入口运行一次，不直接修改测试脚本。
2. 通读 handout，把每道题标注为推导、编码、评测或写作。
3. 对 shape、梯度和 mask 使用小尺寸手算样例与单元测试。
4. 调参前保存可复现基线，记录 seed、版本、命令、耗时和指标。
5. 提交前对照课程 Honor Code 与当年 handout 要求。
