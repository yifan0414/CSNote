# LLM MOC

这是 `06-LLM` 的总入口。先按需要选择学习路线，再进入概念笔记；课程材料保留授课顺序，多模态学习统一衔接 `07-MultiModal`。

## 从基础到语言模型

如果基础概念还没有连起来，先读 [[数学与模型学习路线]]，沿“模型表达→预测目标→求导→优化→训练代码”建立联系。

进入语言模型时，按下面的顺序阅读：

1. [[00-分词]] → [[01-词向量]]：文本怎样变成模型可以处理的输入。
2. [[02-RNN]] → [[03-LSTM与GRU]] → [[04-Seq2Seq]]：序列状态怎样传递，固定表示有什么限制。
3. [[05-Attention]] → [[06-transformer]]：怎样按内容访问序列信息，并组成完整模型。

[[从 Seq2Seq 到 Attention 再到 Transformer]] 从信息访问方式串起架构演变。[[dive-to-attention]] 保留专题对话；[[07-Transformer]] 是 CS224n 对应课程笔记。它们可作为主讲义的补充。
