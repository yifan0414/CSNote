# 数学与模型学习路线

这里把基础笔记连成几条可实际阅读的路线。每篇笔记围绕一个问题形成完整解释，正文负责主线，折叠 callout 提供证明、算例和补充。

## 1. 先理解模型为什么长这样

从 [[从线性模型到多层感知机]] 开始：为什么需要偏置，为什么只叠加线性层不够，隐藏层怎样构造新特征。然后读 [[线性回归：最小二乘与参数求解]]，把“选定一个函数形式”与“根据数据求参数”连接起来。

想知道图像模型如何使用空间结构，再读 [[CNN：卷积计算与特征学习]]；想看从分布假设直接得到分类器的路线，读 [[高斯朴素贝叶斯：从类别分布到分类]]。

## 2. 再理解怎样评价预测

[[贝叶斯公式与参数推断]] 先讲联合概率、条件概率、似然与后验，再连接到参数估计。

沿着这个基础，[[损失函数的概率解释]] 回答“为什么某种任务采用某种损失”，从最大似然走到分类、回归和序列建模。

接下来有两个不同的深入方向：[[交叉熵：从概率预测到分类梯度]] 追踪一次分类预测怎样产生梯度；[[KL 散度：定义、性质与方向]] 解释分布不匹配的代价，以及交换两个分布为什么改变优化行为。

## 3. 接着理解梯度怎样算出来

从 [[梯度与方向导数：怎样描述多变量函数的局部变化]] 理解局部变化，再用 [[雅可比矩阵与局部线性化]] 把一个输出推广到多个输出。[[行列式与体积缩放]] 补充局部变换与体积变化的关系。

[[矩阵微分与求导技巧]] 将这些概念整理为可操作的求导方法。随后用 [[两层神经网络的反向传播推导]] 走完一次从损失到每层参数梯度的过程。

## 4. 最后理解梯度怎样变成训练

[[梯度下降与 SGD：从损失变化到批量参数更新]] 讲一次参数更新与批量估计；[[从 SGD 到 AdamW：动量与自适应优化]] 解释为什么要引入历史梯度、尺度估计和独立的权重衰减；[[学习率与调度策略]] 讲基础步长怎样随训练变化。

落实到代码时，用 [[PyTorch 损失归约与梯度累积]] 检查 `sum`、`mean`、梯度累积和更新时机。然后可以衔接 [[06-LLM/04-训练与推理/多GPU训练过程|多 GPU 训练]]，或回到 [[LLM MOC]] 进入 Transformer 主线。

## 跨篇符号约定

同一对象在不同笔记中会使用不同字母，跨篇阅读时按下面的约定对照：

| 对象 | 常见写法 | 出现位置 |
|---|---|---|
| 模型对标签的预测 | $\hat{y}$、$\widehat{\boldsymbol{y}}$ 或 $q_\theta$ | 交叉熵、矩阵微分、两层神经网络、损失函数 |
| 目标标签（one-hot 或软标签） | $y$ 或 $\boldsymbol{y}$ | 同上 |
| 参考/真实分布 | $p$ 或 $p^*$ | 信息论与贝叶斯笔记 |
| 模型分布 | $q$ 或 $q_\theta$ | 信息论与变分推断笔记 |
| 参数 | $\theta$（权重与偏置统称） | 最优化笔记 |
| 第 $t$ 步的（随机）梯度 | $g_t$ | 最优化笔记 |

分类笔记中已统一用 $\widehat{\boldsymbol{y}}$ 表示模型预测、$\boldsymbol{y}$ 表示目标；信息论与贝叶斯笔记中的 $p,q$ 是分布记号，与上述预测记号不是同一层含义。
