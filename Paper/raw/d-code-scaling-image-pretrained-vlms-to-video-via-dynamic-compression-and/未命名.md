# 1. 重新定义研究目标

D-CoDe 的后续如果走 query-conditioned，很自然是：

$$
\max_C I(C(V,q); a \mid q)
$$

但你不想这样做，那么目标应该变成：

$$
\max_C \mathbb{E}_{q \sim \mathcal{Q}} I(C(V); a_q)
$$

subject to：

$$
|C(V)| \ll |V|
$$

也就是说，压缩器不知道未来会问什么问题，但它要尽量保留对大量潜在问题都有用的信息。

这对应的任务不是：

> 给定问题，找相关视频证据。

而是：

> 给定视频，构建一个可复用、紧凑、信息覆盖充分的视频表示。

这和 D-CoDe 的核心差异是：

| 方法     | 压缩对象                                  | 是否依赖问题     | 适合场景               |
| ------ | ------------------------------------- | ---------- | ------------------ |
| D-CoDe | video tokens + question decomposition | 部分依赖 query | 单个复杂问题             |
| 你的方向   | universal video memory                | 不依赖 query  | 多问题、多轮问答、视频索引、离线压缩 |

# 2. 最自然的 paper idea

## Query-Agnostic Video Memory Compression for Image-Pretrained VLMs

核心问题：

> 如何在完全不知道问题的情况下，把一个视频压缩成 image-VLM 可读的 compact memory，同时最大限度保留事件、状态变化、对象交互和细粒度视觉证据？

我会把方法设计成三层：

$$
V \rightarrow \text{Frame Tokens} \rightarrow \text{Event Memory} \rightarrow \text{Object-Action-State Memory}
$$

也就是不再只做 frame/token compression，而是构造一个**视频记忆结构**。

---

# 3. 为什么 query-agnostic 更值得做？

D-CoDe 里 question decomposition 的强增益，本质上说明 image-VLM 不擅长直接从长视频 token 中抽取证据。

但 query-conditioned decomposition 有几个问题：

1. 每个问题都要重新推理，延迟高；
2. 简单问题容易被过度分解；
3. 子问题由外部 LLM 生成，系统边界不干净；
4. 同一个视频被问多个问题时，重复计算严重；
5. 压缩策略可能过拟合当前问题，损失其他问题需要的信息。

所以 query-agnostic 的研究动机应该是：

> 视频理解系统不应该每来一个问题才重新决定“看什么”；它应该先形成一个稳定的视频记忆，然后让语言模型在这个记忆上回答任意问题。

这更接近人类看视频后的状态：人不是每听到一个问题才重新看视频，而是先形成事件记忆、对象记忆、时序记忆。

---

# 4. 核心 Insight

D-CoDe 的动态压缩主要基于两个假设：

$$
\text{high activation} \Rightarrow \text{important}
$$

$$
\text{low similarity} \Rightarrow \text{non-redundant}
$$

但 query-agnostic setting 下，这两个假设还不够。

因为真正应该保留的不是“显著 token”，而是：

$$
\text{future questions are likely to depend on state changes}
$$

也就是说，视频问答里很多问题最终依赖的不是静态显著性，而是：

1. 谁出现了？
2. 谁和谁交互？
3. 什么动作发生了？
4. 对象状态如何变化？
5. 场景何时切换？
6. 前后事件有什么因果或时间关系？

所以 query-agnostic compression 的核心洞见可以写成：

> 对未来问题最有价值的信息，不是单帧内最显著的视觉 patch，而是跨时间稳定存在的对象、动作边界、状态变化和事件转折点。

# 5. 具体方法设计

## 5.1 Temporal：从 frame sampling 变成 event segmentation

D-CoDe 的 temporal selection 是：

$$
\text{uniform frames} + \text{diverse supplementary frames}
$$

你的方法可以改成：

$$
\text{event boundary detection} + \text{event prototype selection}
$$

具体做法：

1. 对所有帧提取 CLIP / image encoder global feature；
2. 计算相邻帧差异：

$$
d_t = 1 - \cos(g_t, g_{t+1})
$$

3. 根据差异峰值检测 event boundary；
4. 把视频切成若干 event segments；
5. 每个 segment 内选：

   * 起始帧；
   * 中间代表帧；
   * 结束帧；
   * 最大变化帧。

得到：

$$
V \rightarrow {E_1, E_2, ..., E_K}
$$

每个 event 不只是一个 frame，而是一个小的 temporal unit。

为什么比 D-CoDe 更适合 query-agnostic？

因为它不是为了某个问题找相关帧，而是尽量保留视频的事件结构。未来不管问动作、顺序、原因、变化，都更可能在 event memory 里找到证据。

---

## 5.2 Spatial：从 high-norm token 保留变成 object-persistent token memory

D-CoDe 的 spatial compression 用 token norm 做 salience proxy。但 query-agnostic 里更重要的是对象级持久性。

可以设计一个 object-persistent token selection：

对每个 spatial token $z_{t,i}$，计算三个分数：

### 1. Salience

$$
s_{\text{sal}}(z_{t,i}) = |z_{t,i}|
$$

表示它在当前帧是否显著。

### 2. Persistence

$$
s_{\text{pers}}(z_{t,i}) = \max_{j} \cos(z_{t,i}, z_{t-1,j})
$$

表示它是否属于跨帧稳定存在的对象。

### 3. Change

$$
s_{\text{chg}}(z_{t,i}) = 1 - \max_{j} \cos(z_{t,i}, z_{t-1,j})
$$

表示它是否代表新出现、消失或状态变化的信息。

然后综合：

$$
s(z_{t,i}) = \alpha s_{\text{sal}} + \beta s_{\text{pers}} + \gamma s_{\text{chg}}
$$

这里要小心：persistence 和 change 是相反的，但都重要。

持久对象回答“谁/什么在场”；变化 token 回答“发生了什么”。

所以可以分别保留两类 memory：

$$
M_{\text{object}} = \text{persistent tokens}
$$

$$
M_{\text{event}} = \text{changing tokens}
$$

最后合成：

$$
M(V)=M_{\text{object}} \cup M_{\text{event}}
$$

这比单纯 top-norm 更强，因为它不只是保留视觉显著区域，还保留跨时间的对象轨迹和变化证据。

---

## 5.3 Memory：构造层级视频记忆，而不是一串压缩 token

最终不要只输出一串 visual tokens。可以输出三种 memory：

### A. Scene memory

保存视频的场景段落：

$$
M_{\text{scene}} = {m_1^{scene}, ..., m_K^{scene}}
$$

回答“视频在哪里发生”“场景如何变化”。

### B. Object memory

保存跨帧稳定对象：

$$
M_{\text{object}} = {m_1^{obj}, ..., m_N^{obj}}
$$

回答“有哪些人/物”“谁和谁交互”。

### C. Change memory

保存关键变化：

$$
M_{\text{change}} = {m_1^{chg}, ..., m_L^{chg}}
$$

回答“发生了什么动作”“状态怎么变”。

最后将它们组织成 image-VLM 可读的输入：

$$
[Scene\ Memory] + [Object\ Memory] + [Change\ Memory]
$$

这比 D-CoDe 的 flat compressed tokens 更有优势，因为它把视频 token 变成了结构化记忆。

# 6. 论文的核心创新可以这样写

## 创新一：Event-aware query-agnostic temporal compression

**要解决的问题：**
uniform sampling 和 diversity sampling 都只是在 frame-level 选帧，不能显式保留事件边界和时序结构。

**Insight：**
未来问题通常依赖事件段落，而不是孤立帧。

**具体设计：**
基于相邻帧语义变化检测 event boundary，然后为每个 event segment 构建 compact event prototype。

**为什么有效：**
它保留的是视频的 temporal skeleton，使后续任意问题都能访问事件级证据。

---

## 创新二：Object-change disentangled spatial memory

**要解决的问题：**
high-norm token 不一定是未来问题需要的信息；只保留显著 token 会忽视小物体、交互和状态变化。

**Insight：**
query-agnostic setting 下，最通用的信息应该分成两类：稳定对象和动态变化。

**具体设计：**
把 visual tokens 按 persistence 和 change 分解成 object memory 与 change memory。

**为什么有效：**
object memory 保留“视频里有什么”，change memory 保留“视频里发生了什么”。

---

## 创新三：Reusable video memory for multi-question answering

**要解决的问题：**
D-CoDe 每个问题都要重新 decomposition 和多次推理，无法高效处理同一视频上的多个问题。

**Insight：**
如果视频压缩是 query-agnostic 的，那么压缩结果可以被多个问题复用。

**具体设计：**
对每个视频只构建一次 memory，所有问题共享同一个 compressed representation。

**为什么有效：**
把复杂度从：

$$
O(N_q \cdot C_{\text{video}})
$$

降到：

$$
O(C_{\text{video}} + N_q \cdot C_{\text{QA}})
$$

其中 $N_q$ 是同一个视频上的问题数量。

这会让你的方法在 multi-question video QA、video indexing、long video assistant 场景下比 D-CoDe 更自然。

# 7. 和 D-CoDe 的差异要打清楚

你可以这样定位：

| 维度          | D-CoDe                 | 你的方法                        |
| ----------- | ---------------------- | --------------------------- |
| 核心目标        | 针对当前问题增强视频理解           | 构建可复用视频记忆                   |
| 是否依赖 query  | decomposition 依赖 query | 完全 query-agnostic           |
| temporal 单元 | selected frames        | event segments              |
| spatial 单元  | salient tokens         | object/change memory        |
| 推理方式        | 多子问题多次 VLM 调用          | 一次构建，多问题复用                  |
| 主要优势        | 单问题复杂推理强               | 多问题、长视频、离线索引更高效             |
| 主要风险        | latency 高、过度分解         | 可能保留无关信息，需要更好 memory budget |

# 8. 最关键的实验设计

如果你做 query-agnostic，普通 VideoQA benchmark 还不够。因为单个 question setting 下，query-conditioned 方法天然占优。

你需要设计能体现 query-agnostic 优势的实验。

## 8.1 Multi-question per video setting

对每个视频有多个问题：

$$
{q_1, q_2, ..., q_n}
$$

比较：

1. D-CoDe：每个问题重新 decomposition；
2. 你的方法：视频 memory 只构建一次，所有问题复用。

指标不只看 accuracy，还要看：

$$
\text{Accuracy} / \text{FLOPs}
$$

$$
\text{Accuracy} / \text{Latency}
$$

$$
\text{Accuracy} / \text{Token Budget}
$$

这是你最容易打出差异的地方。

---

## 8.2 Question diversity stress test

把问题分成几类：

1. object recognition；
2. action recognition；
3. temporal order；
4. state change；
5. causal reasoning；
6. counting；
7. spatial relation。

然后看同一个 query-agnostic memory 是否能覆盖多种问题类型。

如果你的方法只在 action QA 上好，但 object QA 差，说明 memory 不够通用。

---

## 8.3 Memory reuse evaluation

定义一个新指标：

$$
ReuseGain = \frac{\text{Acc}}{\text{Total Inference Cost}}
$$

或者：

$$
\text{Cost per answered question}
$$

当每个视频的问题数 $N_q$ 增加时，你的方法应该越来越占优。

理想趋势是：

$$
N_q \uparrow \Rightarrow \text{relative efficiency advantage} \uparrow
$$

这正是 query-agnostic 方法的核心卖点。

# 11. 我认为最强的研究主线

不是“做一个更好的 token compression”，而是：

$$
\textbf{从 query-specific evidence extraction 转向 query-agnostic video memory construction}
$$

这条线比 query-conditioned 更有独立性。

D-CoDe 的问题是：问题来了以后才开始组织视觉证据。
你的方法应该强调：视频看完以后就应该形成一个通用记忆。

这会让论文的 standing 更清楚：

> D-CoDe asks: given a question, what should the model look at?
> Our method asks: before any question is asked, what should a video memory preserve?
