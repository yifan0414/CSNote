- 按 `sample_per_sec=2` 采样视频。

- 合并区间。
- 从这些区间里均匀取 `k` 个最终帧索引。

DINOv2 只在这一步需要：

```bash
bash scripts/cafs.sh <dataset>
```

如果你只跑仓库支持且已有 reward 的这三个：

```text
mlvu
longvideobench
videomme
```

并且目标模型是仓库已有 reward 的：

```text
Qwen2.5-VL-7B-Instruct
Qwen2.5-VL-32B-Instruct
Qwen3-VL-8B-Instruct
```

那就不需要 DINOv2，直接用 `rewards/*.json` 生成 `keyframes/*.json` 即可。

但如果是“其他数据集”，或者同一个数据集但换成没有 reward 的模型，例如别的 Qwen、InternVL、LLaVA，那就需要重新跑 reward pipeline。DINOv2 负责候选帧，目标 VLM 负责给候选帧打分。
