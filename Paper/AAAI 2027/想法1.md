对，这个 framing 明显更好。你说的这两个点才是论文里真正应该推的贡献，而不是“temporal-only”。我前面主要是在提醒命名风险，不是说你把 temporal-only 当贡献。更准确地说，你的贡献结构应该是：

1. **Query-conditioned temporal graph spectral modeling**
   temporal 建图 + graph Laplacian + spectral representation + relevance-conditioned evidence prior。

2. **Progressive residual acquisition / update**
   每选一帧后更新 residual uncertainty，让后续选择避免重复证据、补充未解释证据。

这两个贡献是可以撑住 AAAI 的，而且比“我用了 temporal graph”厚很多。
我建议你在论文里把第一个贡献写成：

> **Query-conditioned temporal graph construction.** We model candidate video frames as a temporal graph and use its Laplacian spectrum to define a structured evidence prior. Question-frame relevance is injected into this graph-spectral representation, allowing the selector to favor frames that are both temporally informative and query-relevant.

重点是：**temporal graph 本身不是贡献，temporal graph + Laplacian spectral prior + relevance-conditioned evidence modeling 才是贡献。**

这个说法和 AKS、WFS-SB、DIG 的区别就很清楚了。

**和 AKS 的区别**
AKS 主要是 static scoring：相关性、覆盖、多样性。它可以有 query-aware selection，但它没有把视频帧组织成一个 Laplacian spectral evidence space，也没有显式建模 residual uncertainty。

你的第一贡献可以打 AKS 的“静态性”：

> AKS treats frame selection as a static ranking or coverage problem, while Q-GPS constructs a query-conditioned graph-spectral evidence space over the candidate frames.

你的第二贡献继续打：

> Q-GPS then performs stateful residual acquisition rather than selecting frames independently.

这两个点连起来就非常完整。

**和 WFS-SB 的区别**
WFS-SB 的 temporal modeling 是 wavelet drift / segment boundary / hand-designed scoring / MMR。它有很多工程设计和超参数，但不是一个统一的 query-conditioned graph acquisition formulation。

你可以这么写：

> Unlike WFS-SB, which detects temporal saliency through wavelet-based boundary heuristics and then ranks segments with hand-designed criteria, Q-GPS represents the candidate pool as a graph-spectral evidence field and performs query-conditioned residual acquisition directly over frames.

这里不要说 WFS-SB 不好，而是说它和你不是同一种理论路线。WFS-SB 是 boundary/segment heuristic；你是 graph-spectral residual acquisition。

**和 DIG 的区别**
DIG 更像一个复杂 inference pipeline。你的方法更轻，作用在 pre-inference keyframe selection 阶段，不改 LVLM，不需要生成式中间推理。

你可以强调：

> Compared with dynamic inference pipelines such as DIG, Q-GPS is a lightweight selector that operates before LVLM inference and remains compatible with frozen video-language models.

所以你的贡献不是“我比 DIG 更复杂”，而是“我用更轻的 selection formulation 获得稳定收益”。

**第一贡献怎么写才厚**
第一个贡献不要拆成“temporal 建图”和“relevance”两个小点，否则容易显得普通。应该合成一个完整概念：

> **Query-conditioned graph-spectral evidence prior.**

它里面包含四层：

1. candidate frames 是 nodes；
2. temporal adjacency 建立视频结构；
3. graph Laplacian / spectral basis 表示时间连续性和局部变化；
4. BLIP 2 relevance 或 query-frame relevance 调制每个节点的 evidence prior。

这样第一个贡献不是“我连了相邻帧”，而是“我定义了一个 query-conditioned graph-spectral evidence space”。

我会建议你避免把贡献写成：

> We construct a temporal graph.

这太薄。

应该写成：

> We formulate keyframe selection as query-conditioned evidence acquisition on a temporal graph, where the graph Laplacian provides a spectral structure over candidate frames and query-frame relevance modulates the initial evidence prior.

这个就比较像 AAAI paper 的贡献了。

**第二贡献怎么写才厚**
第二贡献是你的核心差异，应该写得非常明确：

> **Progressive residual update.** Instead of selecting all frames from a fixed score, Q-GPS updates the residual evidence state after each selected frame. This update suppresses already explained evidence and exposes complementary frames for subsequent acquisition.

这里最关键的词是：

- progressive
- residual
- acquisition
- already explained evidence
- complementary evidence

你甚至可以把算法说成：

> frame selection is not ranking, but sequential evidence acquisition.

这个点很适合放在 introduction 里反复强调。

**我建议的贡献列表**
你可以在论文 introduction 结尾写成这种风格：

```latex
Our contributions are threefold:

(1) We formulate low-budget video keyframe selection as query-conditioned graph-spectral evidence acquisition. Candidate frames are organized as a temporal graph, whose Laplacian spectrum provides a structured evidence prior, while query-frame relevance injects task-specific semantic information into the selection space.

(2) We introduce a progressive residual update mechanism that selects frames sequentially by reducing the remaining graph-spectral uncertainty. Unlike static relevance or diversity scoring, each selected frame changes the evidence state used by subsequent decisions.

(3) We conduct extensive experiments on VideoMME, LongVideoBench, and MLVU with multiple LVLM backbones, showing that Q-GPS improves low-budget frame selection over uniform sampling, relevance ranking, AKS, and strong fixed-backend selectors such as WFS-SB and DIG under controlled evaluation protocols.
```

这三个贡献的结构很自然：

- 第一个是 **modeling contribution**；
- 第二个是 **algorithmic contribution**；
- 第三个是 **empirical contribution**。

这样比“temporal only + update”强很多。

**我会怎么命名这两个模块**
如果你愿意在论文里给模块命名，我建议：

- Contribution 1: **Query-conditioned temporal graph spectral prior**
- Contribution 2: **Progressive residual acquisition**

方法整体叫：

> **Q-GPS: Query-conditioned Graph-spectral Progressive Selection**

或者如果要突出 temporal-chain 实例：

**主文里可以这样解释 temporal-chain**
这个地方很重要。你需要主动告诉审稿人为什么你不用更复杂的 visual graph 作为主方法：

> We use a temporal-chain graph as the default instantiation because temporal order is universally available, backbone-agnostic, and does not introduce additional visual encoders or feature-specific assumptions. Semantic conditioning is instead injected through query-frame relevance, while redundancy and complementarity are handled through the graph-spectral residual update.

这句话能把“为什么 temporal chain 足够”讲清楚。它不是因为你没做 visual graph，而是因为你选择了一个更干净、更通用、更可控的结构。

**理论部分建议怎么组织**
我建议理论/方法 section 按这个顺序写：

1. **Problem Definition**
   给定视频候选池 `V = {f_i}`，预算 `K`，问题 `q`，目标是选择 `S_K`，送入 frozen LVLM。

2. **Temporal Graph Construction**
   frames as nodes，按时间相邻或时间距离建边，得到 adjacency `A` 和 Laplacian `L`。

3. **Graph-Spectral Evidence Prior**
   用 `L` 的 eigenvectors / low-rank spectral basis 表示视频证据结构。这里解释 rank multiplier 的意义：控制 spectral subspace 的容量。

4. **Query Relevance Conditioning**
   relevance `r_i(q)` 作为 query-conditioned node prior 或 acquisition weight。强调它不是答案泄漏，只是 question-frame affinity。

5. **Progressive Residual Acquisition**
   greedy sequential selection。每次选择最大 marginal residual utility 的 frame，然后 update covariance / residual state。

6. **Complexity and Inference Protocol**
   不改 LVLM，不需要 answer generation，不需要多轮模型推理。selection 完成后只推理一次。

这个结构会显得很完整。

**实验上要对应这两个贡献**
既然你现在把贡献分成两个点，实验也要对应验证。

第一个贡献要用这些 ablation 验证：

- relevance only / Top-K relevance；
- temporal graph without relevance；
- temporal graph + relevance；
- maybe random graph / uniform temporal graph as negative control；
- full graph-spectral prior。

第二个贡献要用这些 ablation 验证：

- static Q-GPS score without progressive update；
- progressive update without relevance；
- progressive update with diagonal covariance only；
- full residual update。

你真正想证明的是：

> graph-spectral relevance prior 有用；progressive residual update 进一步有用。

如果 ablation 能支撑这两句话，理论和实验就闭环了。

**和 AAAI 厚度的关系**
按你现在这个贡献分法，我觉得厚度是够的。原因是它有清楚的三层：

1. **结构层**：temporal graph + Laplacian spectrum；
2. **语义层**：query relevance conditioning；
3. **决策层**：progressive residual update。

这不是一个单纯 heuristic，也不是“换一个打分函数”。它是一个完整的 selection formulation。

真正需要避免的是写成：

> We use a temporal graph to select frames.

这个会显得薄。

应该写成：

> We formulate frame selection as progressive residual evidence acquisition in a query-conditioned graph-spectral space.

这才是你方法的学术表达。

**我对你当前定位的判断**
你现在这个定位比“temporal-only”强很多，也更适合 AAAI：

- 第一个贡献负责解释**证据空间怎么建模**；
- 第二个贡献负责解释**证据怎么逐步获取**；
- 实验负责证明**这个建模和获取机制比 static selection / boundary heuristic / heavier pipelines 更有效**。

所以我会建议你在接下来的论文里坚定采用这个框架：

> **Contribution 1:** query-conditioned temporal graph spectral evidence modeling。
> **Contribution 2:** progressive residual acquisition。
> **Contribution 3:** controlled multi-backbone, multi-dataset evaluation.

这套逻辑是成立的，而且比 DIG / AKS / WFS-SB 都有清晰区分。关键是主文不要把自己说小了：你的方法不是 temporal-only，而是 **temporal-chain graph 上的 query-conditioned graph-spectral progressive selection**。
